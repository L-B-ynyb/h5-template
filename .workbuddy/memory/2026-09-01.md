## 修复存量类型错误（CI 前置阻塞）

- `src/libs/socket.ts` 引用 `window.__APP_CONFIG__.WS_URL`，但全局变量未声明且文件未被任何地方引用（死代码），导致 `vue-tsc` 类型检查失败、CI 无法跑绿
- 新增 `src/types/global.d.ts` 声明 `Window.__APP_CONFIG__?: { WS_URL?: string }`
- `socket.ts` 改为 `window.__APP_CONFIG__?.WS_URL ?? ''` 安全兜底，防止运行时未注入时崩溃
